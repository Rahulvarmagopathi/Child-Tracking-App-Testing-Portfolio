# MSc Child Monitoring & Location Tracking System — Testing Portfolio

## Project Overview
This portfolio contains the comprehensive test documentation, test strategies, and system logic analysis for a Child Monitoring and Location Tracking mobile application. The platform was designed to assist parents in tracking their children's real-time locations and maintaining device security boundaries.

### My Role: Graduate Software Tester & Requirements Coordinator
While the software engineering prototype was executed across a collaborative development pipeline, my core responsibility was to act as the **Lead Software Tester**. I translated system requirement documents into structured testing documentation, focusing heavily on logical verification, user data privacy, and edge-case validation.

---

## 🛠️ Testing Core Focus Areas

### 1. Functional System Testing
* **Live GPS Mapping:** Verifying that coordinate telemetry data synchronizes seamlessly from the child device to the parent interface.
* **Authentication Controls:** Ensuring relational database boundaries securely isolate individual parent-child account nodes.

### 2. Non-Functional Privacy & GDPR Compliance
* Analyzing strict data minimization principles to ensure location logs are processed securely and handled safely.
